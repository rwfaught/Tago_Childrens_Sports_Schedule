Making a schedule change

Update the Google Sheet

For ordinary schedule changes, use the Public Schedule tab. The live website reads that tab automatically.

Open the editable Google Sheet and select Public Schedule at the bottom.

Find the event row, then change the cell that needs updating. Google Sheets saves your edits automatically.

Wait briefly—published-feed changes may take roughly 1–5 minutes to appear.

Open the live schedule and refresh the page. Your change should now be visible.

Helpful rule: One row represents one schedule event. Find that row and edit only the information that changed.
Common fields

What the columns mean

You usually only need to change the field that is different. These are the important fields in plain language.

Child
Whose event it is.
Sport
For example, volleyball, softball, or football.
Date
The event date.
Event Type
Game, practice, tournament, or another kind of event.
Opponent / Event
The opponent or event name.
Start Time
When it starts; use TBD if it is not known yet.
End Time
When it is expected to end, if known.
Home / Away
Whether the event is at home or away.
Location
Where the event takes place.
Team / Level
The team, grade, or level.
Status
Confirmed, Pending, Conditional, or Cancelled.
Conditional?
Whether the event depends on a decision or condition.
Public Notes
Short information that is safe to show on the public website.
Adding a new event

Copy a similar row

The easiest safe method is to copy or duplicate an existing row that looks similar, then replace its fields with the new event's information.

Choose a similar event for the same child and sport.

Copy or duplicate that row, then update the date, event type, opponent/event, times, location, and other fields that differ.

Choose the correct status. If the time is unknown, leave Start Time as TBD and use Pending.

Wait a few minutes, then refresh the live schedule to check the new event.

Statuses and TBD information

Use the status that fits

These statuses help the family understand how certain an event is.

Confirmed

The event is set.

Pending

The event is expected, but details are not final yet.

Conditional

The event depends on a decision or condition.

Cancelled

The event will not happen.

TBD is okay: If the exact time is not known yet, leave the time as TBD and keep the event as Pending. Change it to the confirmed time and status later.

Public vs. private

Choose the right sheet tab

Public Schedule

This tab feeds the public live website. Only put schedule information here that is okay for anyone with the published website link to see.

Private Notes

This tab does not feed the public website. Use it for private family logistics and notes.

Privacy reminder: Keep private family information out of Public Schedule. Do not make the whole Google Sheet public; ordinary Google sharing permissions are enough.
Print / PDF

Take the schedule with you

The main page shows the whole family. Click Lea, Tala, or Kal to open a child-only page. Child pages offer All Dates, Week, and Day; the Family Calendar offers a selected Week or Day for everyone.

Use the previous/next buttons or date picker to select the date or week you need. Select Print / Save PDF to print a paper copy or save only the schedule view currently displayed.

Because the website is live: Generate a fresh PDF later whenever you want it to reflect the latest published schedule.
If something looks wrong

Try these quick checks

Wait a few minutes for the Google Sheet change to publish.

Refresh the live schedule page.

Verify that the row is in the Public Schedule tab and that the cells contain the expected information.

If it still does not appear, contact Roger rather than trying to fix the website.
